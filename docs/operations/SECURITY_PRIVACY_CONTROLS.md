Original bytes remain in temporary device OPFS as well as the private server copy
after consent. Validated words, manifest and signed results live in browser IDB;
CSRF and transient upload capabilities stay in memory. Backend holds only bounded
grants/action digests and expiring access descriptors; renderer holds bounded
temporary intent/generation descriptors and scratch. No database/history/queue.
Provider-internal retention differs from deleting our Files/bucket objects.
Device Clear is best-effort; closing a tab cannot erase bytes, RAM or downloaded
copies. Independent expiry/retry obligations remain on storage outages/restart.

Corrected cross-boundary issues: concurrent metadata publications recheck access
capacity after await; disconnected stalled readers are explicitly canceled and
their locks released, even with injected transports that ignore abort; Range
status/start/end/total/length must match the actual request before returning media.
Compressed/non-JSON requests are rejected instead of expanding untrusted input.
The storage policy accepts only integer zero retention; negative values fail closed.
Browser copy now describes original/proxy cloud/provider transfers and final TTL.

Dependency manifests/lock and server-only imports remain unchanged; no new
package, model, font, container or install script was added. Local source/fixture,
tracked-media, content-error and boundary scans support code claims only.
Registry vulnerability feeds, live image/package/license scans, complete codec/
font notices, sample/contributor rights and saved vendor controls are unverified.
No key or real filename/content/account identifier belongs in this record.

Alerts are advisory. Process counters and time/body/byte limits are enforced in
code; global monetary caps, restart/rollout multiplication and new anonymous
sessions require owner acceptance and vendor limits before public paid enablement.
On a suspected incident, disable paid/live and renderer intake first, preserve
content-free aggregate evidence, drain owned work, retry/verify deletion and
rotate owner-managed keys separately. Never log payloads or call providers merely
to prove shutdown. CL-014 audits this local revision; CL-015 owns release evidence.
