The locked demo journey is:

1. The visitor starts with the curated sample or uploads one supported,
   owned/licensed conversation.
2. ClipBuilder shows honest analysis stages.
3. Analysis returns zero to four grounded candidates, targeting three strong
   choices without padding. The curated sample always has exactly three.
4. The visitor previews candidates and selects exactly one. Zero candidates
   produces an honest no-candidate state, never a manual-range fallback.
5. ClipBuilder automatically builds the chosen 10–60 second vertical clip with
   active-speaker framing, the fixed `clean-emphasis` caption profile, and
   sparse transcript-grounded contextual visuals.
6. The visitor reviews the completed composition in a read-only preview and
   confirms one render.
7. ClipBuilder renders one MP4 for preview and download.

Do not add or imply an editor, chat interface, prompt box, manual trim/range,
transcript or caption correction, caption styling/density choice, headline
control, crop/focus control, visual/layout/timing control, editable timeline,
proposal/diff/apply workflow, edit history, undo, or redo.
