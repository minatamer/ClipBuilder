## Owner research — picture sources and Gemini tools, 2026-10-06

Research only: these are proposed alternatives, not an approved provider,
rights/privacy policy change, implementation or live quality result. Public
official documentation/catalogs were inspected; no credentials, Gemini calls,
image downloads, cloud changes or Git action were used. The three previously

The current selected planner uses `gemini-3.8-flash`, JSON output and explicitly
empty tools; its prompt also forbids tools/URLs. Gemini proposes briefs, and the
backend performs Commons retrieval. Google ownership does not enable search in
that request automatically.

Google now documents [Google Image Search grounding](https://ai.google.dev/gemini-api/docs/image-generation)
for `gemini-3.1-flash-image`: web images become generation references. Current
limitations exclude real-world people retrieved from web search. The existing
[Generate Content documentation](https://ai.google.dev/gemini-api/docs/generate-content/image-generation)
also describes source-page/image URLs and source-image click-through requirements.
This is not yet evidence that a standalone downloader or baked MP4 export complies.
Google's [grounding terms](https://ai.google.dev/gemini-api/terms#grounding-with-google-search)
require associated search suggestions and restrict extracting links for another
purpose. Obtain a suitable integration interpretation before using grounding as
an asset-harvesting pipeline. Ordinary [web grounding](https://ai.google.dev/gemini-api/docs/google-search)
provides current information/citations; it is not the documented image tool.

An independent option is ungrounded generation of illustrative generic scenes
from validated briefs. [Current standard Developer API pricing](https://ai.google.dev/gemini-api/docs/pricing)
lists Flash Image at USD 0.067 per 1K image: two/three image outputs total USD
0.134/0.201, excluding input/text and search charges. Search has 5,000 monthly
free requests shared across Gemini 3.x, then USD 14/1,000; one model request may
perform multiple searches. These are published prices, not measured clip costs.
This would introduce extra paid generation and require separate approval/budget;
the existing planner/focus call should remain unchanged during such a trial.

| [Pexels](https://www.pexels.com/api/documentation/) | Recommended first trial for generic people, activities and technology photographs. Its [stock license](https://www.pexels.com/license/) permits adaptation but differs from the current PD/CC0-only policy. Actual game screenshots need a separate source. |
